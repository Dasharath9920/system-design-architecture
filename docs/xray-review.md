# X-Ray technical review

Reviewed 2026-10-06. The diagrams are teaching models with illustrative values, not measured production topologies. Primary references are linked inside each component and algorithm layer.

| Component      | Boundaries checked                                                                                                                                                                                                                                                                                            |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PostgreSQL     | Statement vs transaction snapshots; physical tuple versions and HOT; locks still exist; WAL-before-data and configured commit durability; receive vs replay lag; slots retain WAL; index access methods are distinct.                                                                                         |
| Redis          | Serialized command execution is scoped separately from I/O/background threads; Cluster has 16,384 slots, not a generic hash ring; foo maps to slot 12182; asynchronous failover may lose acknowledged writes; LRU/LFU are approximate; pipelining, transactions, Pub/Sub and Streams have distinct semantics. |
| Kafka          | Ordering is per partition; partition count bounds useful group concurrency; ISR differs from KRaft controller quorum; acks=all and minimum ISR are distinguished; transactions do not make arbitrary external effects exactly once.                                                                           |
| Load balancer  | L4 connections vs L7 requests; health detection delay; draining vs crashing; least-connections is not a CPU measurement; provider fail-open behavior is not universalized.                                                                                                                                    |
| CDN            | Cache keys and reuse policy matter; misses, conditional requests and freshness are different; edge selection is not necessarily geographic distance.                                                                                                                                                          |
| DNS            | Resolver issues queries, authoritative servers return referrals/answers; caches avoid repeating the full chain; TTL does not imply instant global convergence; DNSSEC is not encryption.                                                                                                                      |
| API gateway    | Authentication does not grant resource permission; gateway, proxy, load balancer and mesh roles overlap but are not interchangeable.                                                                                                                                                                          |
| Queue          | Lease-based example is explicitly scoped; effect-before-ACK can redeliver; atomic idempotency boundaries matter; RabbitMQ/SQS/Kafka contracts differ.                                                                                                                                                         |
| Search         | Index acknowledgement differs from refresh visibility; index is derived data; analysis, postings, shard ranking and merge have distinct roles.                                                                                                                                                                |
| Object storage | Completion publishes multipart objects; ETag is not universally MD5; object, file and block interfaces differ; provider durability layouts are not asserted.                                                                                                                                                  |
| WebSocket      | HTTP/1.1 Upgrade is scoped; connection order does not imply durable delivery across reconnects; app-level replay/ACKs are explicit.                                                                                                                                                                           |
| Kubernetes     | Controllers, scheduler and kubelet watch/write through the API; persisted intent differs from readiness; convergence is not instantaneous; etcd quorum is distinct from workload availability.                                                                                                                |
| Rate limiter   | Token, leaky, fixed and sliding windows differ; distributed accounting requires atomicity; local allowances can multiply a global budget.                                                                                                                                                                     |
| Authentication | OAuth delegates access, OIDC adds identity; PKCE binds the exchange; client calls resource with access token; ID tokens have a different purpose; JWT is not inherently encrypted or superior.                                                                                                                |
| Multi-region   | Fencing precedes promotion; async lag exposes RPO; routing convergence contributes to RTO; CAP is a partition-time trade-off, and PACELC also addresses normal-operation latency.                                                                                                                             |

Algorithm traces distinguish quorum intersection from linearizability, current-term Raft commitment from arbitrary log replication, approximate cache policies from exact algorithms, and idempotent effects from delivery guarantees. LSM is labeled as a storage alternative, not PostgreSQL's default engine.

## Architecture and lifecycle

- The outer React Flow instance stays mounted. X-Ray owns a separate internal layer in the same canvas area and restores the captured outer viewport on exit.
- Outer playback pauses on entry. It remains paused on exit so the learner decides when to resume. Challenge actions, hints, phase and Time Machine stage are retained.
- Only the current internal layer mounts. Renderer, core content, advanced content and algorithms are loaded dynamically. Node views are memoized; demo updates occur at step boundaries.
- Demos use the existing elapsed-clock convention. Completion stops animation; reset clears values and failures. Backward stepping reconstructs prior values rather than retaining future state.
- Keyboard users can inspect nodes, follow deeper links and return with Escape. Background controls become inert. Entry focus is restored on exit. Reduced motion removes camera travel and edge animation.

## Coverage boundaries

This implementation covers the requested initial 15 components and the listed foundational algorithm traces. MySQL/InnoDB and other phase-two technology internals are not substituted with PostgreSQL content. Queue and cloud-provider examples disclose their implementation scope. Sources and version notes should be re-reviewed when the authored behavior changes.

Validation lives in `tests/xray.test.ts` (catalog integrity, references, scoped matching, critical behavior) and `tests/xray.spec.ts` (navigation, playback completion/reset, exact viewport return, focus, challenge/Time Machine preservation, mobile and reduced motion).
